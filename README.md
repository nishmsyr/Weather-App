# 🌦️ Weather App

A simple and user-friendly web-based weather application that provides real-time weather information for any city using the OpenWeatherMap API.

## 🧰 Features

- 🌍 Search weather by city
- 📍 Get current temperature, humidity, wind speed, and description
- ⛅ Weather icon based on real-time condition
- ⚡ Responsive and clean user interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- OpenWeatherMap API
